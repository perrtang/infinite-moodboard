v0.54.3 更新說明

Infinite Moodboard · 發布日期：2026-10-26

更新內容

  • 調整跨站來源政策，讓 Google Picker 可以驗證網站網域，分享連結的路徑、檔案 ID 與查詢參數不會隨來源標頭送出。
  • 加入第二帳號開啟指定分享檔案的開發驗收頁，讀回物件與檢視／編輯權限，不修改作品或分享權限。

修正

  • 移除與 Google Picker 網域驗證衝突的 same-origin 來源政策，改用 strict-origin-when-cross-origin。
  • 部署檢查會阻止不相容的來源政策再次上線；金鑰格式正確不再被視為完成真實分享驗收。

注意事項

收件者仍須以獲得檔案權限的 Google 帳號連結 Drive。第一次開啟時，請在 Google 選檔視窗選取分享連結指定的同一份檔案。

此版本保留 drive.file 最小範圍與網域限制。未變更作品的儲存位置、既有分享權限或雲端更新的衝突保護。

回復與備份

更新前可下載 .moodboard 備份。程式版本保留 Git 備份標籤與原始碼；開啟失敗時不會以空白內容取代作品，也不會自動覆蓋雲端檔案。
